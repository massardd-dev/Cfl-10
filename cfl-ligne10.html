Sauvegarde iCloud
Comment ça marche :
1. Appuyez sur Exporter → le fichier cfl-l10.json sera téléchargé.
2. Dans la feuille de partage iOS, choisissez Enregistrer dans Fichiers → iCloud Drive.
3. Pour restaurer, appuyez sur Importer et sélectionnez le fichier depuis iCloud.
Installer l'app
Sur iPhone avec Safari :
1. Ouvrez cette page dans Safari.
2. Appuyez sur l'icône Partager (carré + flèche).
3. Choisissez « Sur l'écran d'accueil ».
4. L'app apparaît comme une app native, sans barre Safari.
